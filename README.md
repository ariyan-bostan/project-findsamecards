## 📖 About The Project

Find Same Cards is a browser-based memory game developed to practice frontend development with React and TypeScript.

The project uses reusable React components, TypeScript for type safety, and Bootstrap for styling and responsive layouts.

## ⚙️ Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/ariyan-bostan/project-findsamecards.git
   ```

2. Navigate to the project directory:

   ```bash
   cd project-findsamecards
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.
